# Переписка Николая Эрдмана и Ангелины Степановой (1928–1935)

## Источник

Датасет составлен по книге **«Письма: Николай Эрдман. Ангелина Степанова, 1928–1935 гг.»** с комментариями и предисловием Виталия Вульфа.


## Структура датасета

Файл: `erdman_stepanova.csv`. Каждая строка соответствует одному выделенному письму или сообщению.

| Столбец | Содержание |
| --- | --- |
| `date_raw` | Исходная запись даты из текста; отсутствует, если дата не найдена |
| `author` | Автор: `Эрдман` или `Степанова` |
| `recipient` | Получатель, определенный по автору в рамках переписки двух людей |
| `text` | Текст письма после удаления сносок  и нормализации пробелов |
| `lemmas` | Лемматизированный текст в нижнем регистре, без пунктуации и числовых токенов |
| `word_count` | Число словесных токенов в письме  |
| `day` | День месяца, если установлен |
| `month` | Номер месяца, если установлен |
| `year` | Год, если установлен

## Извлечение и очистка данных

1. FB2-файл разобран как XML с помощью `BeautifulSoup`. Выбран раздел `1928-1935 гг.`; тексты выделены по подзаголовкам-разделителям `* * *`. Блоки воспоминаний исключены из извлечения.
2. Авторы определены регулярным выражением по подписям в последних трех абзацах. Пять нераспознанных случаев атрибутированы вручную по содержанию писем.
3. Из текстов удалены маркеры сносок (`[1]`, `[23]` и подобные). Абзацы объединены, лишние пробелы и переносы строк устранены.
4. Для лемматизации использована русская модель spaCy `ru_core_news_sm`. Сохранены токены, состоящие только из букв; их леммы приведены к нижнему регистру. По этим же токенам рассчитан `word_count`.
5. Даты извлечены регулярными выражениями преимущественно из начала и конца писем. Названия русских месяцев и римские обозначения месяцев заменены цифровыми; день, месяц и год вынесены в отдельные столбцы.

## Отсутствующие и неполные даты

Если дата не обнаружена, её значение в `date_raw` остаётся пустым; соответствующие части даты в `day`, `month`, `year` также остаются пропущенными.

Если в тексте указаны только день и месяц, они сохраняются, а год остается пропущенным. Недостающие значения автоматически не подставляются по соседним письмам. Исходные формулировки сохраняются в `date_raw` для ручной проверки.
